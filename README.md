# 📝 Scribbly Notes

Scribbly Notes is a simple and user-friendly note-taking application that helps users quickly write, organize, and manage their notes. It provides a clean interface for capturing ideas, reminders, and important information.

## ✨ Features

- Create and save notes.
- Edit existing notes.
- Delete notes when no longer needed.
- Simple and easy-to-use interface.
- Organize your thoughts in one place.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
