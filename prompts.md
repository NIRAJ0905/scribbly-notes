1. Scribbly Notes — Section A, Project 5
Prompt 1 — Plan the app
Build an offline-first web app called Scribbly Notes. It should turn typed notes into attractive notebook pages that look handwritten. Before coding, inspect the project folder, propose a simple architecture, and ask questions only if something essential is missing. Keep the app beginner-friendly and explain the files you create.
Prompt 2 — Main editor and live preview
Create a clean interface with a text area for entering notes and a live notebook-page preview. The preview should update as the user types. Use readable lined, grid, and plain paper styles. Make the layout responsive.
Prompt 3 — Handwriting appearance
Add at least three handwriting styles, selectable ink colours, and paper styles. Add subtle natural variation to word position, size, and angle so the output feels like a notebook, but keep it legible. Bundle font files locally where licensing permits so the app works offline.
Prompt 4 — Multiple pages and export
Make long notes flow onto multiple pages without cutting a line in half. Add export to image and PDF, plus a print-friendly layout. Test a long, three-page note and fix page breaks.
Prompt 5 — Test and polish
Test empty input, long notes, special characters, page breaks, font loading, image export, PDF export, and offline use. Fix errors before adding decoration. Do not describe a feature as complete unless it works.
